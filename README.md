# Miami, New Year (Dec 31, 2026 – Jan 7, 2027)

Family trip site: a single static page (`index.html`) with:

- Day-by-day itinerary explorer linked to an interactive map (Leaflet, vendored in `vendor/leaflet`)
- Live Miami Beach forecast from Open-Meteo, plus a snorkel go/no-go check for Jan 2 and a beach-day tip
- Booking tracker, key-dates timeline and packing list (ticks are saved in each viewer's browser)

Publish with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
