# Miami, together (Dec 31, 2026 – Jan 7, 2027)

## 👉 Website: https://novashining.github.io/Travel/

Share that link with family. It works on phones and computers.

A photo-led family trip site with practical planning tools:

- **Moments**: six photo stories that open in a viewer and jump to their day
- **Day-by-day explorer**: plan, photo and an interactive map for each day (numbered stops and routes)
- **Weather-aware plan**: pick the Jan 2 adventure and which of Jan 4–6 is the city day; the itinerary rearranges itself (the garden day never lands on a Monday). "Plan from the forecast" uses the live Open-Meteo forecast once the dates are in range.
- **Sharing**: the Share button uses the phone's share sheet; plan choices are included in the link; link previews show a photo
- **Planner**: booking tracker, key dates, packing list and tips (ticks are saved in each viewer's browser)

Static site with no build step: `index.html`, `css/site.css`, `js/app.js`. Fonts and the map library are in `vendor/`, photos in `assets/img/` (credits in the page footer). Hosted with GitHub Pages from `main`.
